# 📊 Earth Data Xarray NetCDF → Zarr Demo

A demonstration project showing how to efficiently work with large environmental datasets (e.g., ERA5) using **xarray**, **Dask**, **NetCDF**, and **Zarr**.
This repository illustrates best practices for:

- Lazy loading and chunked computations with **Dask**
- Subsetting and storing multidimensional arrays
- Converting large NetCDF files to scalable **Zarr stores**
- Exploring computation graphs and performance trade-offs
